بويوسف ٣ - V031.5 - تدقيق مقارنة فلاتر بكين بغوانزو

السبب: V031.4 عرضت 4 مجموعات رئيسية (الكل/المطاعم/الكافيهات/المخابز)، بينما غوانزو تعرض تصنيفات المطاعم مباشرة كفلاتر رئيسية وتعرض وسوم الكافيهات عند اختيار الكافيهات.

الإصلاح الفعلي:
- بكين: الصف الرئيسي الآن يشبه غوانزو: الكل، المطاعم بحسب جنسية المطبخ المتوفر فقط، الكافيهات، المخابز.
- الكافيهات: عند الاختيار تظهر لوحة أنواع الكافيهات (الكل، سياحي، ذو إطلالة، تراثي، مميز) الموجودة فعلًا.
- المخابز: تعرض لوحة أنواع المخابز؛ أُلغي تمامًا فلتر الحلويات التقليدية مع بقاء البطاقات.
- الفلاتر تلتف تلقائيًا على الجوال وتمنع التمرير الأفقي الخاص بالفلاتر.
- البحث العائم يختار تصنيف المطعم المحدد، أو الكافيهات أو المخابز، ثم ينتقل للبطاقة.
- لا إضافات أو حذف أو تعديل لأي سجل بيانات؛ لا تغيير لمدن أخرى أو فنادق أو أقسام أخرى.

المقارنة:
- طريقة عرض تصنيفات المطاعم: مطابقة للهيكل المباشر في غوانزو.
- طريقة عرض أنواع الكافيهات: مطابقة لفكرة التصنيفات الفرعية في غوانزو، مع الحفاظ على وسوم بكين المتاحة فعليًا.
- الاختلاف الباقي طبيعي: غوانزو لديها مطاعم وفئات ووسوم إضافية لا توجد في قائمة بكين الموثقة، ولم تُنسخ هذه الأماكن أو الفئات.
- طريقة التمرير: بكين تستخدم التفاف الأزرار دون شريط أفقي، تنفيذًا لطلب المستخدم السابق.

عدد السجلات الظاهرة في مطاعم بكين: 25 (مطاعم 12، كافيهات 8، مخابز 5)؛ لم يتغير.

التحقق المنفذ: تحقق ملفات JavaScript بواسطة node --check (عند توفر Node)، فحص سلامة ZIP، ومقارنة بصمات كل ملفات المصدر: الملفات المختلفة فقط index.html وdata/other-cities-ui.js وdata/beijing-v0314.css.
التفاعل داخل Chromium: يُذكر منفصلًا فقط إذا تم اختباره. AMAP/DiDi داخل الهاتف: غير مختبر.

تفصيل الأعداد: {'مطاعم': 12, 'مخابز': 5, 'كافيهات': 8}

اختبار Chromium فعلي عبر Playwright: نجاح عند عرض 1440 بكسل و390 بكسل. نجحت فلاتر العربية (4)، التركية (3)، الهندية (1)، الكافيهات (8)، المخابز (5)، فئة الكافيهات ذات الإطلالات (4)، وفلتر الكل (25)، والبحث العائم المؤدي إلى فودينغ، وبقاء فنادق بكين (14) كما هي. لم تظهر أخطاء JavaScript. قائمة الكافيهات الفرعية لا تظهر قبل اختيار الكافيهات، ولا شريط أفقي في الفلاتر. اختبار AMAP/DiDi داخل التطبيق الفعلي لم ينفذ.
