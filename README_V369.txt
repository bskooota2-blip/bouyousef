بويوسف ٢ – V369 – ٨ نوفمبر ٢٠٢٦
النسخة مبنية على V368.
إضافة ستة مواقع مخابز سياحية (بما فيها فرعان منفصلان لسولت أونيون) إلى قسم غوانزو ← المطاعم والكافيهات ← المخابز.
إضافة Magic Base Cafe بطابع هاري بوتر إلى غوانزو ← المطاعم والكافيهات ← الكافيهات السياحية.
القائمة الكاملة للمطاعم والكافيهات تعرض الأماكن السبعة أيضًا. الأسماء الصينية والعناوين غير المؤكدة لم تُخترع؛ يرجى التأكد عبر AMAP قبل الزيارة.
إبقاء إضافات شنغهاي الخمسة وحالة الحلال التحفظية كما في V368.
