# تقرير التنفيذ – بويوسف ٢ V041.43

النسخة الأساسية: bouyousef-main.zip (آخر مرفق). لم يتم تعديل بويوسف ٠ أو النشر على GitHub.

## التفعيل الإلزامي
1. افتح مشروع Supabase الحالي المستخدم في بويوسف ٢، ثم SQL Editor → New query.
2. شغّل ملف BouYousef2_V041_43_Supabase_Setup.sql مرة واحدة. لا تمسح أي كود أو جدول قديم. يتطلب الجدولين by3_admin_members وuser_favorites الموجودين في الترحيلات الأصلية؛ إذا غاب أحدهما يتوقف التنفيذ ويتراجع تلقائيًا.
3. تحقق من أن UUID لحساب المدير الحقيقي موجود في by3_admin_members عبر لوحة Supabase المصرح بها؛ لا تضف أي حساب آخر. لا تشارك كلمة المرور أو مفتاح الخدمة.
4. بعد اعتمادك ونشر النسخة على نفس رابط HTTPS، افتح حسابي وسجل الدخول بالحساب المعتاد ثم اضغط إعادة التحقق من الصلاحية. عند ظهور تأكيد المدير، ادخل إلى غوانزو/الأسواق واضغط القلب والقلم واختبر أهم الأماكن.
5. افتح الموقع بحساب عضو عادي على جهاز أو نافذة أخرى بعد التحديث؛ يجب ظهور النجمة والملاحظة دون القلم. تحقق من حذف التوصية والملاحظة أيضًا.

## التنفيذ
- جميع المدن الـ11 تستخدم محركي عرض غوانزو والمدن الأخرى، وتم تعديل المسارين، بما في ذلك فلاتر مطاعم بكين الخاصة وفلتر مناطق هاينان.
- قائمة الخادم تحصر 1083 مكانًا عامًا مؤهلًا من أصل 1174 سجلًا؛ 91 سجلًا مستبعدًا من التوصيات (لم تُحذف من الملفات). لا تُنشر بطاقة المدير الخاصة.
- جداول by43_public_catalog وby43_editorial محمية بـ RLS دون منح قراءة/كتابة مباشرة للمتصفح. RPC by43_is_admin يفحص القائمة الأصلية، وby43_set_editorial يتحقق من المدير ومن مفتاح المكان العام ويحدث مفضلته وتوصيته في معاملة واحدة. RPC القراءة يرد فقط بالنص والمعرف والنجمة دون UUID المدير.
- ملاحظات نصية بحد 1000 حرف وتعرض باستخدام textContent. لا تُنشر بيانات تجريبية. لا توجد توصيات جاهزة؛ الأماكن القديمة المفضلة لا تُنشر تلقائيًا، بل عند اختيار المدير مجددًا. إذا تعذر التحقق، تبقى المفضلة الشخصية وحدها متاحة مع تنبيه صريح؛ لا تُنشر التوصية.
- عند إضافة أماكن جديدة مستقبلًا يلزم إضافة مفاتيحها العامة إلى قائمة الخادم by43_public_catalog ضمن ترحيل موثوق، وحذف المفاتيح من القائمة عند تحويل مكان إلى خاص (بعد معالجة السجلات التابعة). الواجهة تدعم المدن الجديدة من دون إنشاء محرك عرض منفصل.
- نظام مستقل لبويوسف ٢؛ لم تُنسخ ملاحظات بويوسف ٠ من جدولها المختلف ولم تُحذف.

## نتائج الاختبارات
- فحص syntax عبر Node للملفات المعدلة: ناجح.
- 18 اختبارًا برمجيًا محاكيًا: نجاح فحص الدور، منع تعديل العضو والضيف، استبعاد السجلات الخاصة، حفظ وحذف الملاحظات والتوصيات، عداد الفلتر، البحث، فشل الحفظ وعدم فقد الملاحظة، فهرسة 11 مدينة.
- تعذرت معاينة Chromium بسبب ERR_BLOCKED_BY_ADMINISTRATOR (محاولتا HTTP وHTTPS). لم تُلتقط صور فعلية، ولم يتم اختبار كل البطاقات بصريًا أو الهاتف أو وظائف حسابات Supabase الحية أو تنفيذ SQL فعليًا. لا يعد الاختبار المحاكي إثباتًا لصلاحيات الخادم الحي أو المزامنة بين جهازين.
- تم فحص بصمات SHA-256 لكل ملف أصلي، وتطابق ملفات بيانات المدن بالكامل.
