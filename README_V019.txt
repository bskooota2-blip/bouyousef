بويوسف ٣ — V019 — أزرار التنقل أسفل صفحات غوانزو

أساس المشروع: V018.
التعديل: إضافة زرين أسفل محتوى صفحة غوانزو وكل قسم من أقسامها الثمانية، بعد قائمة الأماكن وزر عرض المزيد:
1) ⬆️ العودة إلى الأعلى: تمرير سلس إلى بداية الصفحة الحالية (مع مراعاة إعداد تقليل الحركة).
2) 🏠 العودة إلى الصفحة الرئيسية: الانتقال إلى #home حيث تظهر بطاقات المدن.

الأزرار تظهر فقط في مسارات مدينة غوانزو؛ ولا تظهر في المدن الأخرى أو الصفحة الرئيسية.
تم الحفاظ على أسماء الأسواق والمطاعم والكافيهات وبيانات المواقع وملفات الصور دون تغيير.
فحص JavaScript في الصفحة وملفات البيانات: ناجح.
فحص وجود الزرين مرة واحدة ووضعهما بعد القسم: ناجح.
الاختبار التفاعلي بمتصفح Chromium: تعذر إكماله لأن بيئة التشغيل تحظر الوصول إلى localhost (ERR_BLOCKED_BY_ADMINISTRATOR).
اختبر الأزرار عبر GitHub Pages قبل اعتماد النسخة للزوار.
