بويوسف ٣ — V041 — ملاحظات التنفيذ

التعديلات: القائمة اليمنى بستة أزرار صغيرة، جديد التطبيق كرابط ثانوي حتى لا تُحذف الوظيفة، إخفاء زر البحث العلوي مع الحفاظ على البحث العائم، ربط WhatsApp/Snapchat وWeChat QR الأصلي، خدمات السفر والرحلات داخل المتجر، واجهة تشجيع التسجيل، بطاقة إحصاء الأعضاء.

تحذير أمني: قفل واجهة العضوية داخل موقع ثابت لا يحمي ملفات HTML/JS/JSON والصور المنشورة للجميع. قبل نشر سياسة عضوية مدفوعة/خاصة يجب نقل البيانات المحمية إلى Supabase بصفوف RLS وواجهات API تتحقق من هوية المستخدم على الخادم. نموذج المعاينة الحالي عبارة عن حاجز واجهة فقط، وليس حماية وصول فعلية.

بطاقة الأعضاء: وظيفة Supabase Edge Function في supabase/functions/member-count/index.ts. لا تعمل حتى تُنشر الوظيفة إلى مشروع Supabase نفسه وتُضبط أسراره بطريقة آمنة. الحساب الحقيقي لا يختلق، بل يظهر «غير متاح» حتى تجهز الوظيفة. اعتمدت الوظيفة RPC get_visit_dashboard_v2 لتمييز المدير؛ تأكد أن هذه الوظيفة ترفض غير المدراء من قاعدة البيانات فعليًا. لا ترفع service_role إلى المتصفح أو إلى GitHub.

صور أيقونات الرحلات وQR من ملفات المستخدم/التصاميم المعتمدة دون تغيير محتواها. WhatsApp يفتح رابط محادثة، Snapchat يفتح صفحة الحساب (لا ضمان لمحادثة مباشرة)، WeChat QR لا يضمن محادثة مباشرة.

لم يتم رفع هذه النسخة إلى موقع بويوسف ٢. اختبار iPhone/Android الفعلي وSupabase يتطلبان أجهزة وخدمة متصلة.
