# V041.49 — إصلاح ظهور قلم المدير

1. افتح مشروع Supabase الحالي، ثم SQL Editor ثم New query.
2. شغّل ملف SQL المرفق V041.49. لا تحذف الجداول أو الملاحظات القديمة.
3. راجع نتيجة admin_accounts؛ إذا كانت 0، فالقائمة لا تضم أي مدير. من Authentication > Users انسخ معرف حساب المدير الحالي (UUID)، ثم أضفه في Table Editor إلى by3_admin_members، إذا لم يكن موجودًا. لا تضف أي حساب آخر.
4. بعد نشر النسخة المعتمدة على رابط الموقع المعتاد، حدّث المتصفح Ctrl+F5 وسجّل الخروج ثم الدخول. في حسابي اضغط إعادة التحقق من الصلاحية.
5. بعد ظهور تأكيد المدير، افتح غوانزو > الأسواق. القلم بجانب القلب. اختبر حفظ ملاحظة ثم ظهورها بحساب عضو آخر دون القلم.

التعديلات: استخدام الجلسة الفعلية من نظام العضوية بدل نسخة localStorage، رسائل تشخيص محددة لغياب الوظيفة أو انتهاء الجلسة أو رفض الصلاحية، إعادة التحقق وإعادة تحميل التوصيات، إصدار جديد لروابط الملفات لمنع الكاش. SQL يعيد تهيئة الوظائف الأصلية ويجهز جداول الاعتماد والمفضلة عند غيابها دون منح صلاحية لأي حساب تلقائيًا.

الاختبارات: Node syntax ومحاكاة ظهور القلم للمدير وإخفائه عن العضو والضيف والمكان الخاص، ومعالجة غياب RPC وانتهاء الجلسة وإعادة التحقق وتسجيل الخروج. لم يُختبر SQL أو تسجيل دخول فعلي على Supabase الحي، ولم يتم النشر. السبب الفعلي على جهاز المستخدم لا يمكن تأكيده قبل فحص نتيجة التحقق.
