بويوسف ٢ – V041.33

1) أضيف مطعم قصر عثمان التركي (Ottoman Palace / 奥斯曼土耳其餐厅) في شينزن > المطاعم، مع عنوانه وأسماء البحث العربية والإنجليزية والصينية، وبدون تكرار.
2) عُدّل اسم بطاقة المدير في غوانزو ليوضح أنها مخصصة لمراكز العلاج الطبيعي والتدليك.
3) أصل ميزة المدير موجود مسبقًا في V041.32؛ تتطلب قاعدة Supabase الخاصة وصلاحية المدير المصرّح بها ليظهر المحتوى.
4) بيانات المراكز الخاصة لا توضع في ملف الموقع المنشور، بل في سكربت SQL منفصل يطبق في Supabase SQL Editor فقط.
5) المراكز الأصلية الثلاثة تقدم توينا/تدليكًا تقليديًا؛ لا تدّعي هذه النسخة أنها جميعًا مراكز علاج طبيعي طبية مرخّصة.
6) لم تتغير أي مدن أو بطاقات أخرى، ولم يُنشر الموقع.
