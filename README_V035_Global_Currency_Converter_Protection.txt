نطاق التنفيذ
-------------
إنشاء حاسبة HTML/CSS/JavaScript في قسم «صرف العملات» وحده.
تصميم سماوي/أبيض وحدود ذهبية بلوحة أرقام كبيرة، واختيار عملات عالمي، ومبالغ سريعة، وثلاثة أزواج عملات شائعة، وتبديل العملتين، ونسخ النتيجة.
القيمة الأولية 1000 يوان صيني CNY إلى الدينار الكويتي KWD.
أسماء العملات العربية/الإنجليزية/الصينية عبر Intl.DisplayNames، ورموز ISO المتاحة للمتصفح، مع استيعاب الرموز الإضافية القادمة من مزود البيانات حال توفر الشبكة.
تظهر أعلام لبعض العملات الشائعة، ورمز محايد عندما لا يتوفر علم مناسب.
ليس كل رمز متاحًا لبيانات التحويل؛ ترفض الحاسبة عرض سعر غير موثّق.

مصدر الصرف
-----------
Frankfurter v2 (https://frankfurter.dev/)
نقطة السعر: https://api.frankfurter.dev/v2/rate/{base}/{quote}
نقطة العملات: https://api.frankfurter.dev/v2/currencies
التوثيق: https://frankfurter.dev/javascript/
المصدر مجاني ومفتوح ولا يتطلب API key؛ يعرض أسعارًا مرجعية من مزودين رسميين لا أسعار معاملات بنكية لحظية.
يُعرض تاريخ السعر الذي يُرجعه المصدر دون ادعاء تحديث في الوقت الفعلي.
لا يحتوي المشروع على سعر ثابت افتراضي، وعند تعذر الشبكة لا تعرض الحاسبة مبلغًا محوّلًا مزيفًا.
الأسعار التي تظهر في الاختبارات الآلية كانت محاكاة معزولة بقيمة مفترضة 0.04321، ولا تمثل سعر يوم الاختبار؛ لقطات الشاشة النهائية تعرض حالة انقطاع الاتصال لا هذه القيمة.
لم يكن بالإمكان التحقق من استجابة API الحية من بيئة التشغيل بسبب تعذر الاتصال الخارجي؛ ينبغي اختبار الربط على GitHub Pages أو متصفح له اتصال بالإنترنت.

الملفات والحدود
---------------
index.html: إضافة عنصر الصفحة وعناصر الربط المحددة لصرف العملات فقط: إدراج CSS وJavaScript، إخفاء شاشة «قيد التجهيز» لهذا القسم، إظهار صفحة الحاسبة عند المسار المناسب، واستدعاء وظيفة عرض الحاسبة.
assets/currency-v035.css: تنسيق جديد محدود بالمعرّف by35ExchangePage وفئاته.
data/currency-v035.js: منطق الحساب والتنسيق والترجمة والبحث الداخلي وقراءة سعر الصرف.
README_V035_Global_Currency_Converter_Protection.txt: هذا التقرير.
SHA256_V035_Comparison.csv: قائمة SHA-256 لكل الملفات الموجودة في النسخة الأساسية والجديدة للمراجعة.
لم تُحذف ملفات أصلية، ولم يتم تعديل بويوسف ٢.

تم وضع الحاسبة في نسخة مستقلة، وليست معتمدة نهائيًا قبل مراجعة المستخدم.
