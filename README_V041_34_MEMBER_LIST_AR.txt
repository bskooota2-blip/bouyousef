بويوسف ٢ — V041.34 — عرض الأعضاء المسجلين (المدير فقط)

التعديلات:
- زر «👥 عرض الأعضاء» داخل لوحة المدير بعد ظهور الإحصاءات.
- جدول منظم: اسم العضو (إن حفظه عند التسجيل)، البريد الإلكتروني، تاريخ التسجيل، آخر دخول، تأكيد البريد.
- تنقل بين الصفحات بواقع 50 عضواً، مع زر إغلاق.
- دالة Supabase جديدة: supabase/functions/member-list/index.ts
- حُفظت الوظيفة السابقة member-count وبيانات المدن والمتجر والإحصاءات كما هي.

خطوات التفعيل الضرورية مرة واحدة:
1. افتح Supabase > Edge Functions > Deploy a new function > Via Editor.
2. سمّ الوظيفة بالضبط member-list ثم الصق محتوى supabase/functions/member-list/index.ts وانشرها.
3. استخدم نفس إعدادات JWT/التحقق المعتمدة في وظيفة member-count.
4. يجب أن يكون حسابك موجوداً في public.by3_admin_members كما هو الحال في عداد الأعضاء.
5. ارفع محتويات مجلد bouyousef-main المحدّث إلى GitHub Pages (أو اختبر محلياً أولاً).
6. سجل الدخول بحساب المدير وافتح لوحة المدير واضغط «عرض الأعضاء».

مهم: لن تُعرض بيانات فعلية حتى تنشر الوظيفة الجديدة على مشروع Supabase الصحيح.
البيانات حساسة: لا تنشر مفتاح service_role في GitHub أو JavaScript ولا تتيح الجدول لغير المدير.
